# 智慧养老服务管理平台

基于 ThinkPHP 8 搭建的养老系统演示项目，按照“养老平台/养老院管理/社区居家养老”类原型的常见模块进行了页面还原与后台化落地。

## 已实现页面

- 运营概览 Dashboard
- 老人档案
- 服务工单中心
- 健康监测
- 护理排班
- 活动通知

## 技术栈

- ThinkPHP 8
- PHP 8.2
- 原生模板 + 静态 CSS
- 演示数据服务层 `app/service/ElderlyCareData.php`

## 启动方式

```bash
php think run
```

默认访问地址：

```text
http://127.0.0.1:8000
```
