# 智慧养老管理系统部署文档

## 1. 项目形态

当前仓库已经是 **正式 ThinkPHP5.1 项目**，不是之前的纯原型骨架。

默认配置采用：

- ThinkPHP 5.1
- PHP 8.3 运行环境
- SQLite 本地数据库（开箱即用）
- PHP 8.x 兼容补丁脚本

如果上线到生产环境，建议切换到 MySQL。

---

## 2. 环境要求

### 基础环境

- Linux / Ubuntu / CentOS
- Nginx 1.18+
- PHP 8.1+（当前已兼容验证到 PHP 8.3）
- Composer 2.x

### PHP 扩展

- pdo
- pdo_sqlite
- sqlite3
- mbstring
- curl
- json
- fileinfo
- openssl

如果切换 MySQL，还需要：

- pdo_mysql

## 3. 部署步骤

### 3.1 获取代码

```bash
git clone <your-repository-url> elderly-care
cd elderly-care
```

### 3.2 安装依赖

```bash
composer install --ignore-platform-reqs
```

### 3.3 执行 PHP 8 兼容补丁

```bash
php scripts/patch_thinkphp_php8.php
```

### 3.4 初始化 SQLite 数据

```bash
php think app:init --refresh
```

执行后会自动创建：

```text
runtime/data/elderly.sqlite
```

并导入默认账号、角色、菜单、老人档案、告警、探访等演示数据。

### 3.5 启动开发服务

```bash
php think run -p 8001
```

访问：

```text
http://127.0.0.1:8001/index.php?s=/admin/auth/login
```

## 5. Nginx 部署示例

```nginx
server {
    listen 80;
    server_name elderly.example.com;
    root /var/www/elderly-care/public;
    index index.php index.html;

    location / {
        if (!-e $request_filename) {
            rewrite ^/(.*)$ /index.php?s=/$1 last;
            break;
        }
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        include fastcgi.conf;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    location ~* \.(jpg|jpeg|gif|png|css|js|ico|svg)$ {
        expires 7d;
        access_log off;
    }
}
```

说明：当前项目已经验证 `index.php?s=/admin/...` 兼容访问方式可用。

## 6. 切换 MySQL 的方式

如果生产环境要改为 MySQL：

### 6.1 修改 `config/database.php`

```php
return [
    'type'     => 'mysql',
    'hostname' => '127.0.0.1',
    'database' => 'elderly_care',
    'username' => 'root',
    'password' => 'your_password',
    'hostport' => '3306',
    'charset'  => 'utf8mb4',
    'prefix'   => 'ec_',
];
```

### 6.2 导入 SQL

```bash
mysql -uroot -p -e "CREATE DATABASE elderly_care DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
mysql -uroot -p elderly_care < database/elderly_care.sql
```

### 6.3 调整初始化逻辑

当前 `InstallerService` 默认会生成 SQLite 数据。如切到 MySQL，建议：

- 保留管理员初始化命令
- 关闭 SQLite 文件创建逻辑
- 改为通过 SQL / Seeder 初始化

## 8. 常见问题

### 8.1 页面报 ThinkPHP 兼容错误

执行：

```bash
php scripts/patch_thinkphp_php8.php
```

### 8.2 `could not find driver`

说明缺少 SQLite 或 MySQL 驱动。

SQLite：

```bash
sudo apt-get install -y php-sqlite3
```

MySQL：

```bash
sudo apt-get install -y php-mysql
```

### 8.3 页面 404

请优先使用：

```text
/index.php?s=/admin/auth/login
```

当前版本已验证该方式稳定可用。

### 8.4 登录后跳转异常

请确认是否保留了：

- `public/.htaccess`
- `route/`
- `config/app.php`
- `application/admin/controller/Base.php`
