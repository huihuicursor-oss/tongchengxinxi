# 智慧养老管理系统部署文档

## 1. 环境要求

### 运行环境

- Linux / CentOS / Ubuntu
- Nginx 1.18+
- PHP 7.2 ~ 7.4
- MySQL 5.7 或 MySQL 8.0
- Composer 2.x

### PHP 扩展建议

- pdo
- pdo_mysql
- mbstring
- json
- curl
- openssl
- fileinfo

## 2. 项目目录说明

```text
/var/www/elderly-care
├── application
├── database
├── docs
├── extend
├── public
└── runtime
```

生产环境中，Web 根目录应指向 `public`，不要直接暴露项目根目录。

## 3. 部署步骤

### 步骤一：上传代码

```bash
git clone <your-repository-url> elderly-care
cd elderly-care
```

### 步骤二：安装依赖

如果你要接入正式 ThinkPHP5 内核：

```bash
composer create-project topthink/think=5.1.* tp5-runtime
```

然后将本项目中的目录迁移到正式项目：

- `application/`
- `public/`
- `extend/`
- `database/elderly_care.sql`

### 步骤三：创建运行目录

```bash
mkdir -p runtime
chmod -R 755 runtime
chmod -R 755 public/static
```

### 步骤四：导入数据库

```bash
mysql -uroot -p -e "CREATE DATABASE elderly_care DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
mysql -uroot -p elderly_care < database/elderly_care.sql
```

### 步骤五：修改数据库配置

编辑 `application/database.php`：

```php
'hostname' => '127.0.0.1',
'database' => 'elderly_care',
'username' => 'root',
'password' => 'your_password',
'hostport' => '3306',
```

## 4. Nginx 配置示例

```nginx
server {
    listen 80;
    server_name elderly.example.com;
    root /var/www/elderly-care/public;
    index index.php index.html;

    location / {
        if (!-e $request_filename) {
            rewrite ^/(.*)$ /index.php?s=/$1 last;
            break;
        }
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        include fastcgi.conf;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    location ~* \.(jpg|jpeg|gif|png|css|js|ico|svg)$ {
        expires 7d;
        access_log off;
    }
}
```

## 5. 本地开发启动方式

如果只预览当前原型版：

```bash
php -S 0.0.0.0:8000 -t public public/router.php
```

访问地址：

```text
http://127.0.0.1:8000/index.php?s=/dashboard/index
```

## 7. 常见问题

### 7.1 页面 404

排查项：

- Nginx 根目录是否指向 `public`
- URL Rewrite 是否生效
- `index.php?s=/dashboard/index` 是否可访问

### 7.2 数据库连接失败

排查项：

- MySQL 服务是否启动
- 账号密码是否正确
- 防火墙是否放通 3306

### 7.3 静态资源不生效

排查项：

- `public/static` 是否部署完整
- Nginx 是否开启正确的 `root`
- 浏览器缓存是否清理
