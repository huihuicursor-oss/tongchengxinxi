# 架构说明

## 1. 总体架构

本项目当前已经升级为 **ThinkPHP5.1 可运行后台系统**，采用服务端渲染模式，围绕养老机构后台管理场景构建。

系统核心包含以下能力：

- 登录认证
- 角色权限控制
- 菜单权限控制
- 老人档案管理
- 健康监测展示
- 服务调度展示
- 告警处理闭环
- 家属探访审核
- 运营日志记录

---

## 2. 分层设计

### 2.1 接入层

路径：

- `public/index.php`
- `public/router.php`
- `route/route.php`

职责：

- 接收 HTTP 请求
- 进入 ThinkPHP5.1 应用生命周期
- 采用 `index.php?s=/admin/...` 方式兼容访问
- 分发到对应控制器动作

---

### 2.2 控制层

路径：`application/admin/controller`

核心控制器：

- `Auth.php`：登录、退出
- `Base.php`：认证校验、权限校验、公共模板变量注入
- `Dashboard.php`：系统总览
- `Elder.php`：老人档案与详情
- `Health.php`：健康监测
- `Service.php`：服务调度
- `Alert.php`：告警处理
- `Visit.php`：探访审核
- `Permission.php`：角色权限分配
- `Menu.php`：菜单管理
- `Log.php`：运营日志

职责：

- 校验登录状态
- 校验角色权限
- 组织页面数据
- 处理表单提交
- 执行业务动作并记录日志

---

### 2.3 服务层

路径：`application/common/service`

核心服务：

- `InstallerService.php`
- `AuthService.php`
- `DashboardService.php`

#### InstallerService

职责：

- 初始化 SQLite 数据文件
- 自动建表
- 自动导入默认角色、菜单、用户和业务演示数据
- 写入操作日志

#### AuthService

职责：

- 登录鉴权
- 退出登录
- 当前用户读取
- 角色权限校验
- 菜单权限过滤
- 用户角色调整
- 角色菜单权限保存

#### DashboardService

职责：

- 汇总首页统计数据
- 聚合告警、探访、服务信息

---

### 2.4 数据层

当前默认数据层基于 **SQLite + ThinkPHP Db facade**。

数据库文件：

```text
runtime/data/elderly.sqlite
```

表设计包括：

- `ec_role`
- `ec_admin_user`
- `ec_menu`
- `ec_role_menu`
- `ec_elder_profile`
- `ec_health_record`
- `ec_service_order`
- `ec_alert_event`
- `ec_visit_record`
- `ec_operation_log`

特点：

- 无需额外数据库服务即可启动
- 适合课程设计、演示、原型转正阶段
- 可平滑迁移到 MySQL

---

### 2.5 展示层

路径：`application/admin/view`

特点：

- 使用 ThinkPHP 模板渲染
- 公共布局 `public/base.html`
- 各业务模块独立模板
- 统一后台视觉风格

样式文件：

- `public/static/css/admin.css`

---

## 3. 权限模型

当前采用轻量 RBAC 模型：

### 3.1 角色

- 超级管理员
- 护理主管
- 前台接待

### 3.2 权限粒度

当前按页面级权限控制：

- `dashboard/index`
- `elder/index`
- `health/index`
- `service/index`
- `alert/index`
- `visit/index`
- `permission/index`
- `menu/index`
- `log/index`

### 3.3 控制方式

- `Base.php` 在每次请求时解析当前控制器/动作
- `AuthService::can()` 判断角色是否有访问权限
- `AuthService::menuItems()` 按角色过滤左侧菜单

---

## 4. 业务闭环设计

### 4.1 告警处理闭环

流程：

1. 健康/行为事件进入 `ec_alert_event`
2. 后台在告警处理页查看待处理事件
3. 管理员提交处理结果与说明
4. 系统写入：
   - `status`
   - `handled_by`
   - `handled_note`
   - `handled_at`
5. 同时写入 `ec_operation_log`

### 4.2 探访审核闭环

流程：

1. 家属预约进入 `ec_visit_record`
2. 后台在家属探访页审核
3. 管理员填写审核结果与说明
4. 系统写入：
   - `status`
   - `reviewed_by`
   - `review_note`
   - `reviewed_at`
5. 同时写入 `ec_operation_log`

### 4.3 权限配置闭环

流程：

1. 在权限管理页选择用户和角色
2. 修改用户角色并保存
3. 选择角色菜单权限并保存
4. 数据更新到：
   - `ec_admin_user.role_id`
   - `ec_role_menu`
5. 同时写入操作日志

---

## 5. 兼容性设计

ThinkPHP5.1 对 PHP 8.1+ 存在若干兼容问题，因此本项目增加了：

- `scripts/patch_thinkphp_php8.php`

修补点包括：

- `ArrayAccess` 返回类型兼容
- `Request::host()` 空值兼容
- `Loader::parseName()` 空值兼容

这使项目能够在当前 PHP 8.3 环境下实际运行。
