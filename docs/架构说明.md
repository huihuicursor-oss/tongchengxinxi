## 1. 项目定位

本系统为智慧养老管理系统原型版，目标是支持养老机构在一个后台中完成老人档案管理、健康预警监控、服务任务调度、家属探访预约与运营日志留痕。

当前代码按 ThinkPHP5 的目录习惯组织，方便后续替换为正式 TP5 内核与数据库模型。

## 2. 架构分层

系统采用轻量 MVC 思路组织，当前分为四层：

### 2.1 接入层

- `public/index.php`
- `public/router.php`

职责：

- 接收 HTTP 请求
- 解析 `s=/模块/动作` 风格路由
- 装载配置、控制器和视图
- 输出 HTML 页面

### 2.2 控制层

路径：`application/admin/controller`

包含：

- `Dashboard.php`
- `Elder.php`
- `Health.php`
- `Service.php`
- `Visit.php`
- `Log.php`

职责：

- 组织页面数据
- 定义页面标题、说明、当前菜单
- 调用数据仓库获取展示所需数据
- 交由视图层渲染

### 2.3 服务层

路径：`application/common/service/DemoRepository.php`

职责：

- 提供页面所需的模拟数据
- 为后续切换数据库模型提供统一出口
- 将“页面展示逻辑”和“数据来源”分离

正式开发时，可将该层替换为：

- ThinkPHP Model
- Service 业务类
- Repository 数据访问层

### 2.4 展示层

路径：`application/admin/view`

职责：

- 使用 PHP 模板输出后台页面
- 统一布局、导航、卡片样式、表格样式
- 实现系统总览、老人档案、健康监测等原型页面

样式资源位于：

- `public/static/css/admin.css`

## 3. 模块设计

### 3.1 系统总览

展示机构经营和照护状态的摘要信息：

- 在院人数
- 护理人员数量
- 当日预警数量
- 待执行服务数量
- 重要通知
- 实时预警列表
- 当日服务计划

### 3.2 老人档案

用于查看老人基础信息和护理级别，后续可扩展：

- 入住信息
- 既往病史
- 紧急联系人
- 护理等级变更记录
- 家属授权信息

### 3.3 健康监测

用于监测关键生命体征与预警事件：

- 血压
- 血氧
- 心率
- 风险等级
- 预警处理进度

后续可接入：

- 智能手环
- 床旁监护设备
- 睡眠监测设备
- 跌倒报警设备

### 3.4 服务调度

用于管理护理、康复、文娱、配餐等任务：

- 服务时间
- 服务内容
- 服务对象
- 执行人
- 执行状态

后续可扩展：

- 自动排班
- 护工工时统计
- SLA 超时提醒
- 服务评价

### 3.5 家属探访

用于管理家属预约来访记录：

- 预约人
- 被探访老人
- 亲属关系
- 探访时间
- 审核状态

后续可扩展：

- 黑名单机制
- 视频探访
- 探访码核验
- 陪诊/外出申请

### 3.6 运营日志

用于记录后台关键操作行为：

- 模块名称
- 操作人员
- 操作动作
- 操作时间

后续可用于：

- 审计追踪
- 风险追责
- 数据恢复辅助
- 报表统计

## 4. 数据库设计思路

当前提供的 SQL 表覆盖系统原型常用实体：

- `admin_user`：后台用户
- `elder_profile`：老人档案
- `caregiver`：护理人员
- `health_record`：健康记录
- `alert_event`：预警事件
- `service_order`：服务工单
- `visit_record`：探访记录
- `operation_log`：操作日志

关系建议：

- 一个老人可有多条健康记录
- 一个老人可有多条预警事件
- 一个老人可关联多次探访记录
- 一个护理人员可对应多个服务工单
- 一个后台用户可产生多条操作日志

## 5. 未来演进方向

### 5.1 接入正式 ThinkPHP5 框架

建议迁移到完整 TP5.1 项目后补充：

- `vendor/`
- `thinkphp/`
- `think`
- 中间件、异常处理
- 配置分环境管理

### 5.2 业务能力增强

建议追加以下子系统：

- 登录认证与 RBAC 权限
- 机构/楼栋/房间管理
- 药品库存管理
- 护理计划管理
- 警报闭环处理
- 数据统计报表
- 微信/短信通知

### 5.3 非功能能力

建议重点建设：

- 审计日志
- 数据备份
- 可观测性监控
- 慢 SQL 分析
- 容灾与恢复
- API 鉴权

## 6. 技术选型建议

### 推荐基础环境

- PHP 7.2 ~ 7.4
- ThinkPHP 5.1
- Nginx 1.18+
- MySQL 5.7 / 8.0
- Redis 5+

### 前端建议

当前原型版采用服务端渲染页面。正式项目可选择：

- 保持 ThinkPHP 模板渲染
- 后台改造为 Layui / AdminLTE
- 或升级为前后端分离架构（Vue + TP5 API）

## 7. 当前实现边界

当前版本重点是：

- 快速搭建原型工程目录
- 体现养老后台核心页面结构
- 补齐数据库初稿
- 提供开发、部署、架构文档

当前尚未接入：

- 正式 TP5 内核
- 登录与权限
- 真正数据库连接
- 表单提交
- 文件上传
- 设备接口联动

这意味着当前仓库更适合用作：

- 毕设/课程设计初版
- 原型转代码演示版
- 后续正式开发的脚手架
